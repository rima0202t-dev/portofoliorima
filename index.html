Tentang Saya

Perkenalkan, saya Rima Anjani, seorang mahasiswi program studi Sistem Informasi di Universitas Cipasung Tasikmalaya. Selama masa studi, saya menemukan minat yang besar terhadap bagaimana data dapat diolah menjadi informasi yang berharga.

Fokus utama saya saat ini adalah pada bidang Data Mining. Saya sangat antusias mempelajari algoritma klasifikasi dan prediksi, dengan fokus khusus pada algoritma K-Nearest Neighbor (KNN).

Dalam melakukan riset dan eksperimen data, saya terbiasa menggunakan bahasa pemrograman Python yang dijalankan melalui lingkungan Google Colab. Platform ini memudahkan saya dalam memproses dataset, melakukan visualisasi data, dan membangun model machine learning yang efisien.
